# bbf-asistan

Bölüm içi araçlara, sistemlere ve bağlantılara tek bir noktadan hızlı erişim sağlayan başlangıç sayfası.

🌐 **Canlı Sürüm:** [bbf-asistan.github.io](https://bbf-asistan.github.io)

## 🚀 Yerel Çalıştırma

Proje tamamen statik dosyalardan (HTML, CSS, JS) oluştuğu için herhangi bir derleme veya bağımlılık kurulumu gerektirmez.

```bash
# Depoyu klonlayın
git clone https://github.com/bbf-asistan/bbf-asistan.github.io.git
cd bbf-asistan.github.io

# Yerel sunucu başlatın
python3 -m http.server 8000
```

Tarayıcınızda `http://localhost:8000` adresini açarak görüntüleyebilirsiniz.
